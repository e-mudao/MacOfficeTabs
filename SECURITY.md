# Security reporting / 安全问题反馈

Please do not publish exploit details, private document titles, or credentials in a public issue. If this repository has GitHub private vulnerability reporting enabled, use **Security → Report a vulnerability**. Otherwise, open a public issue asking the maintainer for a private contact method, without including sensitive details.

请勿在公开 Issue 中发布漏洞利用细节、私有文档标题或凭据。如果仓库启用了 GitHub 私密漏洞报告，请使用 **Security → Report a vulnerability**。否则可在公开 Issue 中只请求维护者提供私密联系方式，不附敏感细节。

Include the affected version, macOS and Office versions, reproduction steps using disposable documents, and the security impact. The project does not currently promise a fixed response time or provide a notarized binary release.

报告中请注明受影响版本、macOS 与 Office 版本、使用可丢弃文档的复现步骤及安全影响。目前项目没有承诺固定响应时限，也没有经公证的二进制发行包。
